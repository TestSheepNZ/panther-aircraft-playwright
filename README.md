# panther-aircraft-playwright
Playwright test framework demonstrator for mock Panther aircraft fuel calculator

PLEASE READ

This code base is designed as a training tool and demonstrator over a piece of best practice automation, please bear this in mind.

Of particular importance, the tests here can be pointed at different builds which can be found on this page...

https://testsheepnz.github.io/panther-all-builds.html

Each of those pages will react differently to this code.

This is a fundamental differentiator of this automation example. It allows you to check different pages for failures.


The pages under test could do with a tidy up sometime as they're getting on for six-years old, and designed to work for 
a Selenium suite as well as this Playwright one.

I'm a test automator, not a particularly great web designer! ;-)

Have fun, and try this out.
